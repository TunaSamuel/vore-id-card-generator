# Department of Predatory Relations — ID Card Generator

A serious, smutty, government-style **Vore Registration ID** generator.

Pure frontend. No accounts, no servers, no data leaves your browser. Perfect for personal gooning or sharing on itch.io.

## Features

- Live preview of a realistic modern ID card
- Front + flipable reverse side
- Portrait photo upload with zoom / pan controls
- Second “belly / interior” image on the back
- Role, Preferred Entrance, Appetite Rating (1–6), Danger Level
- Optional **DANGEROUS / ON WATCH** overlay stamp
- Total Swallowed & Total Digested counters
- Magnetic stripe + official-sounding safety blurb (4 options)
- Multiple color themes + custom colors
- Randomize button
- High-resolution PNG download (print-ready)

## Usage

Just open `index.html` in any modern browser, or host the folder on GitHub Pages / itch.io / any static host.

```bash
# optional local server
npx serve .
```

## Tech

- Vanilla HTML / CSS / JS
- [html2canvas](https://html2canvas.hertzen.com/) (CDN) for PNG export
- No build step, no dependencies to install
